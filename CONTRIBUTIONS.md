# Open Source Contributions & Credits

CareerPropel is built upon a foundation of incredible open-source libraries, frameworks, and developer utilities. We believe in absolute transparency, ethical software development, and giving full credit to the creators whose efforts have paved the way for this platform.

Below is the official ledger of acknowledgements and open-source contributions integrated or adapted within **CareerPropel**.

---

## 🌟 Primary Inspiration: `santifer/career-ops`

We want to give our highest commendation and deepest gratitude to **Santiago Fernández de Valderrama** for his seminal project:
*   **Repository**: [github.com/santifer/career-ops](https://github.com/santifer/career-ops)
*   **Role**: Primary Inspiration & Conceptual Architecture

### 🚀 Capabilities Learned & Integrated:
1.  **Playwright-Driven Job Scraping**: The core scraping architecture utilized in our asynchronous workers for automated job search portal scanning was inspired by the robust, battle-tested Playwright scripts developed in `santifer/career-ops`.
2.  **Automated Resume Tailoring**: The strategic vision of utilizing large language models to dynamically rewrite resume sections for optimized Applicant Tracking System (ATS) matching is heavily influenced by Santiago's custom markdown tailoring engine.
3.  **Core Philosophy**: Transforming job tracking from a simple reactive record-keeping task into an active, high-intensity career operations control center is a direct evolution of the pipeline principles demonstrated in the `career-ops` CLI-first ecosystem.

Santiago’s dedication to open-source software and reducing operational friction for job seekers around the globe has been a continuous beacon for the design and evolution of **CareerPropel**.

## 🛠️ Key Open-Source Libraries & Frameworks

CareerPropel proudly utilizes and builds upon the following foundational dependencies:

| Library / Tool | Primary Purpose in Platform | License |
| :--- | :--- | :--- |
| **Next.js** (Vercel) | Core React framework, server-side rendering, and API routing | MIT |
| **Prisma ORM** | PostgreSQL database schema modeling, connection pooling, and type-safe queries | Apache-2.0 |
| **Playwright** (Microsoft) | Headless browser automation for authentic LinkedIn and Indeed scraping | Apache-2.0 |
| **NextAuth.js** | Federated authentication, session handling, and JWT protection | ISC |
| **Lucide React** | Premium icon sets used throughout our glassmorphic user interface | ISC |
| **Tailwind CSS** | Utility-first styling framework enabling our rich dark-mode aesthetics | MIT |
| **Redis & ioredis** | Asynchronous worker task queue, circuit breaker tracking, and result caching | BSD-3-Clause |
| **Socket.io** | Real-time WebSocket streaming of agent execution logs and timeline states | MIT |
| **speakeasy / qrcode** | Highly secure Multi-Factor Authentication (MFA / 2FA) setup and verification | MIT |
