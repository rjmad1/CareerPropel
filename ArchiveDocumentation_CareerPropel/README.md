# Archive Documentation

This folder contains legacy, superseded, planning-phase, or drifted documentation that is being retained for historical context.

## What Was Archived

- Earlier `docs/` architecture and roadmap material
- Week-by-week status reports
- Phase implementation notes
- Older setup, deployment, security, and websocket guides
- Progress and completion summaries that no longer match the current codebase cleanly

## How To Use This Folder

- Use it for historical intent and prior design rationale
- Do not treat it as the primary source of truth for current implementation
- Verify anything important against `../ActiveDocumentation_CareerPropel/`, `../prisma/schema.prisma`, and current code under `../src/`
