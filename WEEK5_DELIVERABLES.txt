                        ARCHITECTURE DECISIONS
===============================================================================

✓ React Query for server state
  - Optimized caching with staggered stale times
  - Automatic background refetching
  - Built-in error handling
  - Devtools integration

✓ Local useState for form/tab state
  - No need for global state for transient UI state
  - Cleaner component logic
  - Easier to test

✓ Tailwind CSS for styling
  - Utility-first, no custom CSS
  - Consistent color system
  - Responsive design out of box
  - Z-index management for overlays

✓ Domain-driven component organization
  - All components in src/domains/jobs/
  - Clear separation of concerns
  - Reusable hooks
  - Easy to find and maintain

✓ Fixed right-side panel UI pattern
  - Non-blocking detail view
  - Doesn't replace main content
  - Matches Trello/Linear interaction model
  - Easy to close
